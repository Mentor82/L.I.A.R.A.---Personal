## 2. AI System Disclosure (EU AI Act)

### ⚠️ This is an AI System

**LIARA is an Artificial Intelligence System** that uses machine learning models to:
- Generate conversational responses
- Process natural language
- Create embeddings for semantic memory
- Analyze sentiment and emotional context
- Generate images (if Stable Diffusion is enabled)

### AI Risk Classification: **Minimal Risk**

LIARA is classified as a **minimal risk AI system** under the EU AI Act because:
- ✅ It does NOT make high-risk decisions (no credit scoring, no employment decisions, no law enforcement use)
- ✅ It operates locally with full user control
- ✅ It provides transparency about AI-generated content
- ✅ It does NOT use manipulative or deceptive techniques

### How LIARA Makes Decisions

LIARA uses the following AI components:

1. **Large Language Models (LLMs)**
   - Provider: Ollama (local execution)
   - Models: Mistral, Llama, Qwen, etc. (user-configurable)
   - Purpose: Text generation, conversation, reasoning
   - Explainability: Responses are probabilistic based on training data and context

2. **Embedding Models**
   - Provider: sentence-transformers (local)
   - Purpose: Semantic memory, similarity search
   - Explainability: Converts text to 768-dimensional vectors for meaning comparison

3. **Sentiment Analysis**
   - Provider: transformers (local)
   - Purpose: Detect emotional tone in conversations
   - Explainability: Classification based on language patterns

4. **Image Generation (Optional)**
   - Provider: Stable Diffusion (local)
   - Purpose: Generate images from text prompts
   - Explainability: Diffusion-based generative model

### AI-Generated Content Labeling

**All responses generated by LIARA are AI-generated.** The system:
- ✅ Clearly identifies itself as an AI companion
- ✅ Does not impersonate humans
- ✅ Indicates when content is machine-generated (footer: "💬 AI-Generated Response")

### No Manipulative Design

LIARA does **NOT** use:
- ❌ Dark patterns to trick users into sharing more data
- ❌ Emotionally manipulative techniques
- ❌ Subliminal messaging
- ❌ Exploitation of vulnerabilities

## 3. Legal Basis for Processing (GDPR Art. 6)

### Data Processing Legal Bases

| Data Category | Legal Basis (GDPR Art. 6) | Purpose |
|--------------|---------------------------|---------|
| **Account Data** (username, email, password) | Art. 6(1)(b) - Contract performance | Necessary for account creation and authentication |
| **Chat Messages** | Art. 6(1)(a) - Consent | Voluntary use of chat feature |
| **Semantic Memory** | Art. 6(1)(a) - Explicit consent | Opt-in feature for long-term context |
| **Sentiment Analysis** | Art. 6(1)(a) - Explicit consent | Opt-in emotional tracking |
| **Location Data** | Art. 6(1)(a) - Explicit consent | Only for weather/location-based features |
| **Tasks/Events/Notes** | Art. 6(1)(b) - Contract performance | Core functionality of the system |
| **System Logs** | Art. 6(1)(f) - Legitimate interest | Technical troubleshooting and security |
| **Web Search History** | Art. 6(1)(a) - Consent | Only when web search is enabled |

### Consent Logging

LIARA logs all consent actions:
- **Timestamp** of consent
- **Type** of consent (memory, sentiment, location, web search)
- **User ID** associated with consent
- **IP Address** (not logged - privacy-first approach)
- **Consent withdrawal** is logged equally

Consent logs are stored in PostgreSQL and can be exported on request.

## 4. Data Categories & Processing Activities

### 4.1 Personal Data We Collect

#### Essential Data (Required for Service)
- **Username**: Identifier for your account
- **Email**: Account recovery, notifications (if enabled)
- **Password**: Hashed with bcrypt (never stored in plaintext)
- **Registration Date**: Account creation timestamp

#### Optional Data (Requires Explicit Consent)
- **Chat History**: Your conversations with LIARA
- **Semantic Memory**: Long-term contextual knowledge
- **Mood/Sentiment Data**: Emotional analysis of conversations
- **Location Data**: City-level location for weather
- **Web Search Queries**: Search history (auto-deleted after 7 days)
- **Tasks/Events/Notes**: Productivity data

### 4.2 Processing Activities (VVT - Verzeichnis von Verarbeitungstätigkeiten)

| Activity | Purpose | Data Categories | Retention | Legal Basis |
|----------|---------|-----------------|-----------|-------------|
| User Authentication | Account access | Username, email, password hash | Permanent (until deletion) | Art. 6(1)(b) |
| Conversation Processing | AI chat responses | Chat messages, context | 90 days (configurable) | Art. 6(1)(a) |
| Semantic Memory | Long-term context | Embeddings, knowledge graph | Permanent (with consent) | Art. 6(1)(a) |
| Sentiment Tracking | Emotional analysis | Mood scores, sentiment data | 90 days (configurable) | Art. 6(1)(a) |
| Location Services | Weather, timezone | City-level location | 30 days | Art. 6(1)(a) |
| Web Search | Information retrieval | Search queries | 7 days | Art. 6(1)(a) |
| Task Management | Productivity | Tasks, events, notes | Until user deletion | Art. 6(1)(b) |
| Session Management | Active sessions | Session tokens (JWT) | 1 hour | Art. 6(1)(b) |

### 4.3 Data Storage Locations

**ALL DATA IS STORED LOCALLY** on your server:

- **PostgreSQL** (Relational Database)
  - Users, chat history, tasks, events, notes
  - Mood/sentiment data
  - Location data (if consented)
  - Web search history (if consented)

- **Neo4j** (Graph Database)
  - Semantic memory nodes
  - Knowledge graph relationships
  - Embeddings (768-dimensional vectors)

- **Redis** (Cache)
  - Session tokens (1-hour TTL)
  - Temporary data (auto-expires)

- **Filesystem**
  - Generated images (if Stable Diffusion enabled)
  - System logs (technical errors only)

**NO CLOUD STORAGE** - No data is sent to external servers except for optional web searches (see Section 8).

## 5. Your Rights (EU/UK/USA/Canada/APAC)

### 5.1 EU/UK GDPR Rights

You have the following rights under GDPR (Art. 15-22):

#### ✅ Right to Access (Art. 15)
- Request a copy of all your personal data
- **How to exercise**: Use "Export Data" button in Settings

#### ✅ Right to Rectification (Art. 16)
- Correct inaccurate or incomplete data

- **How to exercise**: Use "Delete All Data" button in Privacy Settings

- **How to exercise**: Disable specific features (Memory, Sentiment, Location) in Settings

## 6. Data Retention & Auto-Delete

### Retention Policies (Configurable)

| Data Type | Default Retention | Configurable Range | Auto-Delete |
|-----------|-------------------|-------------------|-------------|
| **Chat History** | 90 days | 7-365 days | ✅ Yes |
| **Web Search History** | 7 days | 1-90 days | ✅ Yes |
| **Location Data** | 30 days | 1-90 days | ✅ Yes |
| **Sentiment Data** | 90 days | 7-365 days | ✅ Yes |
| **Session Tokens** | 1 hour | Fixed | ✅ Yes (Redis TTL) |
| **Semantic Memory** | Permanent | N/A | ❌ Manual deletion only |
| **Tasks/Events/Notes** | Permanent | N/A | ❌ Manual deletion only |
| **Account Data** | Permanent | N/A | ❌ Deleted when account deleted |

### How Auto-Delete Works

- **Daily Cleanup Job**: Runs at 2:00 AM server time
- **Soft Delete**: Data marked as deleted first, then purged after 7 days
- **User Override**: "Delete All Data" button bypasses soft delete

### Data Export Before Deletion

Before deleting your account, you can:
1. Click "Export Data" in Settings
2. Download JSON file with all your data
3. Includes: chats, tasks, notes, events, mood data, memory nodes
